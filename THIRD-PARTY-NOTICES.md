# Third-party notices

Prince's capture worker ships the following third-party components (VIS-04, the Scene Sniff).

## SigLIP base, patch 16, 224 px (vision model)

- **Source:** Google, `google/siglip-base-patch16-224` (revision `7fd15f0689c79d79e38b1c2e2e2370a7bf2761ed`). It ships as the ONNX export `Xenova/siglip-base-patch16-224` (revision `4649052661e53c7000355844105f8a1792088239`), `onnx/vision_model.onnx`, SHA-256 `f89d41bac7f4d4b87e010a467d93f98689d708916ed22f5a07f96fdfa26f475f`.
- **License:** Apache License 2.0, https://www.apache.org/licenses/LICENSE-2.0
- **Paper:** Zhai et al., "Sigmoid Loss for Language Image Pre-Training" (2023).
- **Not committed:** the model is fetched at build time with a pinned digest. The repository contains only text embeddings for a neutral scene vocabulary, derived from the same model's text tower (`src/CompanionCore.Capture.Worker/SceneLabels.json`, regenerated by `tools/scene-labels/make_scene_labels.py`).

- **License:** MIT, © Microsoft Corporation. https://github.com/microsoft/onnxruntime

## DirectML 1.15.4 (`Microsoft.AI.DirectML`)

- **License:** Microsoft Software License Terms for DirectML, as a redistributable for applications that run on Windows. The terms are included in the NuGet package.
- **Diagnostics:** DirectML has no switch of its own. Like Direct3D and GPU drivers, its diagnostic data follows the Windows diagnostic-data setting. Nothing from Prince's screen content passes through it except as GPU input to the local model.
